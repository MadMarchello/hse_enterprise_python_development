# Homework 02 — Распознавание породы собаки

## Задача

Переписать с лекции код распознавания собак (ResNet18 + Oxford-IIIT Pet) и решить две проблемы:

1. **Класс «неизвестная порода».** На лекции чужая собака всегда получала одну из 5 пород (чаще бигля). Нужно модифицировать `argmax`/классификатор, чтобы неизвестные породы относились к отдельному классу «неизвестно».
2. **Расширить до 25 пород.** При увеличении числа классов точность падает — разобраться, почему, и как её поднять (поиграть с `lr`, числом эпох; попробовать два слоя в классификаторе вместо одного).

Групповое задание: к следующему занятию представитель объясняет, что и где поменяли и почему именно так.

## Результат

`распознавание_собаки_v2.ipynb` — 25 пород собак реализованы; 26-й класс «другие» (12 пород кошек) добавлен как частный случай, дообучение последнего слоя ResNet18 с весами loss, оценка accuracy по классам.

Уточнение с третьей лекции (28.09.2026): по Python ничего на почту отправлять не нужно — задание было «поиграться, пощупать» модель. Фокус обсуждения: почему при расширении до 25 пород модель стала уверенно называть всех биглями (в том числе реальные, но неизвестные ей породы) и как из этого выбраться. Решения групп разбирались совместно на занятии.

Итоги обсуждения на занятии 29.09.2026:

- При расширении до 25 классов точность группы упала до ~90%; помогла аугментация (повороты, изменение цветности/яркости — глазу та же картинка, для модели сдвиг признаков).
- Уверенность softmax: ~92% на известных собаках, ~80% на кошках как «других».
- Ограничение решения «кошки = неизвестные»: реальную, но не входящую в датасет породу (например, сибирскую) модель всё равно отнесёт к какому-то известному классу, а всё непохожее на кошек — к мелкой собачьей породе.

**Вывод: класс «другие» таким простым способом (склейка кошек в 26-й класс) реализовать НЕВОЗМОЖНО.** Softmax всегда выбирает один из известных классов, и никакой набор «чужих» примеров не покроет всё многообразие «неизвестного».
- Дальнейшие шаги: больше экспериментов с аугментацией, анализ векторов признаков, подбор сида;
- Минимальное задание отсюда же: вывести shape тензора, написать свой класс Dataset, добавить type hints к двум функциям (см. homework-03.md).
